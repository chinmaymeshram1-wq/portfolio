# Chinmay Meshram · Portfolio

My personal portfolio: projects, experience and certificates.

Built with plain HTML, CSS and JavaScript, using GSAP and Lenis for scroll animations. No build step needed: open `index.html` in a browser.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Page content and layout |
| `style.css` | Styles and theme |
| `script.js` | Animations and interactions |
| `data.js` | Projects and certificates (edit this to add new ones) |
| `assets/` | Photo, project screenshots and certificates |
